Before a mold can be cut, someone has to determine:

→ Which way the two halves should pull apart
→ Which half forms each surface
→ Where the core and cavity meet
→ Which features are trapped and need additional moving steel to release

Today, a tooling expert works much of this out manually — and typically only once the CAD is frozen.

We were evaluated on four criteria:

• Optimal mold direction
• Undercut identification
• Core/cavity classification
• Parting line generation

🧠 𝗧𝗛𝗥𝗘𝗘 𝗜𝗗𝗘𝗔𝗦 𝗗𝗜𝗗 𝗠𝗢𝗦𝗧 𝗢𝗙 𝗧𝗛𝗘 𝗪𝗢𝗥𝗞

1️⃣ 𝗦𝗮𝗺𝗽𝗹𝗲 𝗮 𝗳𝗮𝗰𝗲, 𝗱𝗼𝗻'𝘁 𝘀𝘂𝗺𝗺𝗮𝗿𝗶𝘀𝗲 𝗶𝘁.

A cylinder's normals sweep 360°, so one normal per face describes 𝘯𝘰𝘵𝘩𝘪𝘯𝘨. Every face carries a grid of real surface normals, and every downstream verdict is an area-weighted vote over those samples.

2️⃣ 𝗔𝗻 𝘂𝗻𝗱𝗲𝗿𝗰𝘂𝘁 𝗶𝘀 𝗮 𝗽𝗵𝘆𝘀𝗶𝗰𝘀 𝗾𝘂𝗲𝘀𝘁𝗶𝗼𝗻, 𝗻𝗼𝘁 𝗮 𝗱𝗿𝗮𝗳𝘁-𝗮𝗻𝗴𝗹𝗲 𝗼𝗻𝗲.

From each sample, we cast a ray along the mold opening direction. The face is trapped only when 𝘯𝘦𝘪𝘵𝘩𝘦𝘳 half can pull away from it.

And only rays that 𝘦𝘯𝘵𝘦𝘳 material count as blockers — grazing a neighbouring fillet is not a physical obstruction.

3️⃣ 𝗧𝗵𝗲 𝗽𝗮𝗿𝘁𝗶𝗻𝗴 𝗹𝗶𝗻𝗲 𝗵𝗮𝘀 𝘁𝗼 𝗰𝗹𝗼𝘀𝗲.

It is the curve where core and cavity surfaces meet, chained end-to-end into 𝗼𝗻𝗲 𝗰𝗼𝗻𝘁𝗶𝗻𝘂𝗼𝘂𝘀 𝗹𝗼𝗼𝗽. A discontinuous loop isn't a mold split — it's solid steel.
